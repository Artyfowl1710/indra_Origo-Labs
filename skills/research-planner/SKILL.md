# Research Experiment Planner Skill

1. State a falsifiable hypothesis and the mechanism expected to cause the effect.
2. Identify a credible baseline, datasets/splits, metrics, compute budget, seeds, and stopping criteria.
3. Design ablations that isolate each mechanism and include negative controls where feasible.
4. Predefine primary outcomes and statistical comparisons. Distinguish exploratory analysis from confirmatory tests.
5. Record expected failure modes, confounders, data leakage risks, reproducibility artifacts, and a compute-aware fallback.
6. Never invent results. Label all proposed values as targets or design choices, not measured evidence.
