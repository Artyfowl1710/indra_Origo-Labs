CAPABILITY SECURITY CONTRACTEXPLICIT BOUNDARIES

SkillsMarkdown-only workflow instructions. No executable code. Selected content is bounded and always subordinate to the core safety policy.

PluginsDeclarative JSON manifests + explicitly enabled loopback HTTP JSON endpoints. Only read-only-claimed tools are exposed; the claim is not proof that a service is side-effect-free.

WebHTTPS by default; public DNS/IP checks, redirect revalidation, no environment proxies, rate-limited hosts and capped content.

Parallel agentsIndependent subtasks and dependency-aware task graphs; concurrency is bounded per graph and across the process. Children are read-only and cannot recurse or call plugins.

Docker sandboxDisposable sanitized snapshot, no network by default, non-root command user, CPU/RAM/PID/time caps. Optional bridge networking is a per-run high-risk permission and is not domain-filtered.

Honest limitationPublic URL validation mitigates SSRF but is not a network firewall. Use OS/container egress restrictions for high-assurance isolation.
