# Indra, built by Origo Labs

The product name is **Indra**. Its organization and publisher are **Origo Labs**. The previous team's display attribution has been replaced in owned identity prompts, seeded personas, CLI banners, document templates, copied product guides and installer metadata. Localized dashboard product labels now use Indra. The title uses the central brand configuration. Documentation presents the bundled Indra guide offline at `/guide`; `/docs` remains the backend API reference to avoid a route collision.

Brand changes are applied to source copy, not by rewriting arbitrary chat content. The former chat-wide replacement could corrupt code, executable names, model IDs and links; it has been removed. Conversations now preserve those values. Real provider model names are not renamed.

Internal Python/package names, environment variables such as `HERMES_HOME`, auth headers, storage keys, source directory names, plugin contracts and valid CLI commands remain unchanged for compatibility. Historical import manifests, third-party licenses and copyright notices remain intact. Such technical or provenance references are not product branding. Frozen ZIP files from earlier releases are historical packages and have not been regenerated by this source update.

Only exact, fingerprint-matched auto-seeded personas migrate to the new identity. Custom personas, conversation history, credentials and model weights are not rewritten. Four unchanged built-in product profile personas were migrated locally. Existing conversations retain their established prompt prefix; new conversations load the updated identity. Restart the desktop to load all changed Python modules, and reload its renderer to load the rebuilt UI.

Verification: 241 product regression tests with two skips; 120 focused core tests with one skip; 20 frontend tests; four native renderer checks; production build, compilation, extensions and JavaScript validation. Focused core coverage includes identity/default-persona migration, prompt assembly, console, banners, skin fallback, provider resolution and workspace APIs. Frontend coverage includes preserving executable names, paths, environment variables, provider IDs and factual source links in rendered chat. Native checks verified the hero branding, offline guide, absence of old display branding in that guide, and chat/model-picker loading. Runtime receipts are under `data/test-results/branding-*`.
