# Known limits and honest claims


- This is a Windows x64 release candidate, not a guarantee of compatibility with every judge's machine. Cross-machine installation and code signing remain release work until explicitly recorded as verified.
- Models, rates and access vary by provider/account. A free catalog entry or quota table is not an unlimited-service promise.
- Local inference needs separately acquired runtimes and weights; no large GGUF models are shipped in Git or the installer.
- Windows offline embeddings require the Microsoft Visual C++ v14 x64 runtime. Other optional tools can require separate installations such as Docker, FFmpeg or Tailscale; these are not bundled.
- Speech may depend on hosted services. Device speech, live audio inference and transcription are separate paths.
- The public example proves only its fictional checkout requirements. It is not financial/legal compliance software.
- The phone recording is a separate task. Its dependency SSL failure limits execution claims for the generated program.
- Provenance signatures detect some changes; they do not prove complete capture, trusted time or a non-compromised host.
- Optional integrations and all imported framework tests have not all been independently exercised for this release.
- The preferred three-minute film uses a separate synthetic narrator for both the submission and X. Its product footage is genuine; narration and music are editorial assets. It is not an independent model benchmark.
- Earlier prototype documentation is retained for history and should not override this handbook's native app instructions.
