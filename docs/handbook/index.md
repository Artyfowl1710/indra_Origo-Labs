Indra is a local-first agent workstation from Origo Labs. Start with [installation](installation.md), connect a [model provider](providers.md), then give it a scoped [project and goal](projects.md). The [judge walkthrough](judges.md) reproduces the fictional checkout task without using the author's private data.

The current handbook is authoritative for the native release candidate. Older design documents elsewhere under `docs/` describe earlier prototypes and historical decisions; they are not current installation instructions.

## A useful first session

1. Install the native desktop package and open Indra.
2. Add your own provider key or local endpoint.
3. Copy the example project into a writable folder and select it through Projects.
4. Ask the agent to inspect requirements, propose a plan and establish the failing test baseline.
5. Approve the intended work, inspect generated artifacts and run the independent verifier.

Use the navigation for knowledge, artifacts, phone setup, voice, audit, developer reference and release checks. [Evidence beyond the three-minute cut](evidence.md) is available without presenting every feature as part of one live task.
