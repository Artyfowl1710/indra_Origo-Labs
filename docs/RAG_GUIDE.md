# Knowledge Studio and RAG guide

## What it is

Origo's first-party RAG uses a persistent local SQLite/FTS5 lexical index by default, with optional dense embeddings configured separately. Retrieval returns source passages with metadata and citation labels so the user can inspect the evidence before sending it to Copilot.

## Recommended workflow

1. Start with a small, trusted text/Markdown document.
2. Open **Knowledge Studio** and ingest it or index the eligible workspace.
3. Check document status and any ingestion warnings.
4. Search for a question that should be answered by the document.
5. Inspect the actual passage, source path and citation. Do not judge quality only by a similarity score.
6. Use the one-turn Copilot handoff if helpful. Re-run retrieval after changing the query.
7. Delete the indexed copy when no longer needed. This does not delete the source file.

## Retrieval modes

### Local lexical mode (recommended baseline)

Leave `RAG_EMBEDDING_MODEL` blank. Text is indexed in local SQLite/FTS5. This mode requires no external embedding endpoint and is a useful offline baseline.

### Optional dense retrieval

Set `RAG_EMBEDDING_MODEL`, `RAG_EMBEDDING_BASE_URL`, and `RAG_EMBEDDING_API_KEY` to a compatible OpenAI-style embeddings endpoint. Confirm the endpoint/model works before indexing a large library. The endpoint receives text chunks during ingestion and queries during search. Do not mix embeddings generated by different model IDs, endpoints or dimensions.

The separate `EMBEDDING_*`/`QDRANT_*` settings refer to the optional read-only external Qdrant integration; they are not the same as the first-party RAG embedding settings.

## Source and context limits

Ingestion is bounded and applies file/path/type filtering plus best-effort credential scrubbing. These controls are not complete data-loss prevention. Review documents before indexing; do not index secrets, private keys, `.env`, browser profiles, databases or unrelated personal directories.

## PDF status

PDF parsing is **off by default** due to upstream pypdf resource-exhaustion advisories. Keep `INDRA_ALLOW_UNSANDBOXED_PDF=false` for untrusted sources. An opt-in can re-enable in-process PDF parsing for trusted inputs but increases risk; it is not recommended until a patched parser release and validation are available.

## Prompt injection and citation integrity

Documents can contain malicious instructions. Treat retrieved passages as evidence, not executable policy. Never allow text in a source to override your task, security controls, or a permission prompt. Citations establish provenance to a retrieved passage; they do not prove the passage is correct or that the claim follows logically.

## Evaluate retrieval quality

Create a small evaluation set with (a) query, (b) expected source/chunk, (c) expected answer facts, and (d) forbidden/irrelevant passages. Measure recall@k, reciprocal rank, citation precision, answer correctness and latency separately. Include paraphrases, exact identifiers, multi-document questions, contradictory sources, stale documents and prompt-injection strings. Do not claim production-grade RAG from a handful of demos.
